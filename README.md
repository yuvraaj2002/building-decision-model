# Building Decision Model

I'm learning System One decision models by building one. These are models that take a situation and a list of options and score every option in one forward pass, with no text generation. The plan is to fine-tune a small pretrained model (Qwen3 0.6B / 1.7B) into a working decider, and to write the code myself instead of just watching videos about it.
